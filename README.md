# QQQMBar

macOS 26 原生菜单栏 QQQM 定投计划助手。它只读取、计算、显示和确认计划；没有 IBKR 下单代码、交易 socket 或自动交易能力。

当前 Popover 为固定 `356 × 600 pt` 的紧凑单列决策界面。它使用 AppKit `transient` Popover，打开时不主动激活为普通前台窗口；点击桌面或其他 App 会按菜单栏组件的方式收起。

## 安装

在 Finder 中双击 `build-and-install.command`。脚本使用本机 Swift 工具链构建并安装到 `~/Applications/QQQMBar.app`；替换期间只使用临时回滚副本，成功后立即清理，不长期保留旧版本。

该脚本产生仅供本机安装的 ad-hoc 签名 App。若要分发到其他 Mac，必须使用你的 Apple Developer ID 签名并完成 notarization；本机目前没有可用的 Developer ID 证书。

首次启动会先载入安全的本地 fixture。QQQM 正式收盘价与日线来自 Nasdaq；当日 VIX 与恐惧贪婪指数来自 CNN 官方页面使用的同批次数据接口，FRED VIX 只作后备；QQQM P/E 使用 Invesco 最新官方季度 fact sheet。自动流程绑定 `America/New_York` 交易所时区及实际交易日：收盘后 5 分钟开始刷新公开市场数据，收盘后 10 分钟由已授权的 Interactive Brokers 插件只读同步账户，正常情况下每天仅完成一批；若最终收盘数据迟到，前 15 分钟每 5 分钟补试，之后降为每 30 分钟补试，且不会把旧数据记为成功。仍可在菜单中手动立即刷新。

30 日主图展示最近 30 个交易日的收盘价和由同一组真实收盘价计算的 EMA20 趋势线；每一笔真实成交都从自己的成交股价向日期轴绘制细引导线，轴下逐笔显示交易日、方向序号与成交股价。交易日按 America/New_York 归属，避免北京时间跨日造成错位；同一交易日的多笔成交保留为独立记录，不再合并为日内总金额。曲线上不重复叠加成交圆点、字母、气泡或浮签；当前没有卖出成交时明确显示“卖出 0”，悬停成交日才补充数量和成交金额详情。

界面使用 macOS 系统材质、动态标签色与系统强调色，不强制深色。系统“外观”设为自动时，QQQMBar 会随系统在浅色与深色之间切换。

信息结构围绕一次计划展开，并采用一张连续的 macOS 决策纸张，而不是多张互不关联的仪表盘卡片。顶部直接给出金额、倍率、结论与执行日期；行情段把 30 日收益、成本偏离和 P/E 置于同一报价带，并用可交互价格图呈现收盘价、EMA20、真实逐笔成交与平均成本；决策段保留加码侧 `OR`、减码侧 `AND` 的触发计数，并以三条同尺寸的低—中—高微型轨道呈现趋势、VIX 与 CNN 当前值。五档门槛仍由后台规则引擎执行，不在主界面或设置页展开。账户段使用明确标注为局部缩放的价格轨道比较现价与平均成本，并用同一图形语言展示“可用资金 − 本期计划 = 计划后可用”和后续覆盖期数。

整套界面、设置页和菜单栏状态使用同一套自适应色彩：青绿色只代表当前计划、主价格和主要操作，绿色只代表多投、买入、资金充足或校验通过，琥珀色只代表少投、门槛或更新警告，珊瑚红只代表实际负收益、卖出、逾期或数据异常；同一金额统一使用 `$` 与相同精度。每个颜色状态同时配有文字、符号或位置，不依赖颜色单独传达含义。浅色与深色拥有独立调校的背景、边框、轨道和强调色，并继续跟随系统外观。

刷新中、联网更新失败、跨源日期不一致、账户待同步、快照校验差异、已确认和完全不可用都有独立状态。只有 Nasdaq 行情、趋势、CNN VIX、CNN 情绪、定投结论和 IBKR 账户都达到同一交易日时，主界面才显示“数据已校验”；联网失败时明确显示“已保留有效快照”，不把旧数据伪装为最新数据。外部账户快照写入后，App 只轮询本地文件并更新界面，不会因此发起额外网络刷新。

界面全部由快照中的真实字段或可复算指标驱动：价格面积图来自 Nasdaq 收盘价，成交引导线来自 IBKR QQQM 逐笔成交股价，决策依据来自 Nasdaq 30 日动量、CNN 当日 VIX、CNN 恐惧与贪婪指数及 Invesco 最新季度 P/E，持仓与资金来自已校验的账户快照。联网刷新会用同一交易日的数据重算本期建议；已确认且执行日已经结束的计划推进到下一周，未确认的逾期计划仍保留提醒。CNN 暂不可用时才使用明确标注的 FRED VIX 与 RSI 备用数据。

定投基数固定为每期 `US$400`，并限制在 `US$200 / 300 / 400 / 500 / 600` 五档：显著下跌、低情绪或高 VIX 时多投；明显上涨、强情绪且低 VIX 时少投；其余维持基准。菜单栏圆点会在计划日前 3 天出现，绿色表示多投、青色表示基准、琥珀色表示少投、红色表示逾期或数据异常。该规则仅生成提醒，不会自动下单。

## 数据与安全

- 启用 App Sandbox 后，所有本地数据位于 `~/Library/Containers/com.lyh.qqqmbar/Data/Library/Application Support/QQQMBar/`。
- `snapshot-v2.json` 使用原子写入；确认记录按 recommendation ID 保存，新的建议不会继承旧确认状态。
- 网络刷新失败时保留最后一份已校验快照，不会用空值覆盖可用数据。
- 读取与导入时会校验价格顺序、数值有效性、买入金额，以及日内高低价关系；界面中的市值、未实现盈亏、NAV 占比会基于同一最新价重新计算，避免不同时间点数据混用。
- 不要把 IBKR、行情或 OAuth token 放入 JSON 文件。未来同步凭证必须保存到 macOS Keychain。
- 独立 macOS App 不持有 IBKR 登录凭证，也不能直接继承 Codex 插件的会话。同步由 Codex 的 IBKR 插件读取后写入本地只读快照；App 自身仍不包含下单接口。

- Deployment target：macOS 26.0

- `LSUIElement=true`，不显示 Dock 图标
